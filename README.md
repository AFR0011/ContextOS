# ContextOS

ContextOS is a lightweight MVP for capturing context, reviewing active work, tracking projects, tasks, deadlines, and keeping a clean weekly operating view.

This repository contains a Vite + React + TypeScript deployment-ready MVP.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Vercel

Vercel settings are defined in `vercel.json`:

- Install command: `npm install`
- Build command: `npm run build`
- Output directory: `dist`
