# Archived dev-loop coordination artifacts

These files are historical development-process artifacts from the June 2026 dev-loop workflow. They are preserved for provenance, but they are not current product state, CI inputs, deployment controls, contributor instructions, or an active coordination mechanism.

The former root `shared/` directory was archived here in Batch 12 after the canonical dev-loop control files it referenced, including `DEV_STATE.md`, were no longer part of the active repository. Exact chronology remains available through Git history.

`messages.jsonl` had already been archived here during the earlier repository cleanup; the remaining retired coordination files were moved here without content changes.
